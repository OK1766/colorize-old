# Contributing

All changes to this site go through a GitHub pull request. Do not push straight to `main`, and do not treat a Cloudflare Pages direct-upload as a substitute for a PR.

The Pages project `colorizeold` is direct-upload (not Git-connected). After a PR merges, a separate Pages deploy is still required to change https://colorizeold.com. Keep secrets out of git, chat, and receipts; Pages secrets stay in the Cloudflare project only.
